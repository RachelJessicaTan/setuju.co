# SETUJU — clean premium Next.js website

Run:

npm install
npm run dev

Design direction: clean off-white canvas, editorial typography, restrained olive accent taken from @setuju.co's Instagram palette, compact content, smooth reveal/scale transitions, mobile-first responsive layout. No Next.js dev badge is included.

Photos are temporary Unsplash images, hotlinked by id in `app/page.jsx` (`photos`, `services`, `work`). Replace them with Setuju's own photography — the founder portrait especially — by swapping the ids, or by pointing `img()` at files in `/public`.
